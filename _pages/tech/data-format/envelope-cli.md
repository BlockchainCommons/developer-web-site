_The following courses demonstrate Gordian Envelope functionality
using the Rust-based [envelope-cli reference
app](https://github.com/BlockchainCommons/bc-envelope-cli-rust). It
does so with a hands-on command-line course: you can run the commands
on your local machine and experiment with the results yourself._

## Installing Envelope-CLI

If you don't have `envelope-cli`, you can easily install it with `cargo`.

```sh
cargo install bc-envelope-cli
```
More information on installing Rust and Cargo can be found in [The Cargo Book](https://doc.rust-lang.org/cargo/getting-started/installation.html).
